# 단소 운지법 배우기

숫자 버튼을 누르면 양손 손가락이 해당 계이름의 운지로 움직이고, 누르는 동안 실제 음이 이어지는 모바일 학습 웹앱입니다.

## 주요 기능

- 8개 숫자 키와 옥타브 전환으로 15개 음 학습
- 막음·반막음·엶을 보여 주는 양손 운지 애니메이션
- 저취·평취·역취에 맞춘 지속음과 입김 시각화
- 숫자키, `Shift`, `O`, `Space` 키보드 연주
- `?note=1`부터 `?note=15`까지 음별 바로가기
- 외부 요청 없이 여는 오프라인 단일 HTML 산출물

## 실행

```bash
npm install
npm run dev
npm test
```

`03 모바일 웹앱/단소_운지법_배우기.html`은 별도 서버 없이 파일로 바로 열 수 있습니다.
